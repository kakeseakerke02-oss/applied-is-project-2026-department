1. Streamlit интерфейсінде қазақша st.title, жоба туралы st.write және
st.sidebar жаса. JavaScript, HTML және CSS қоспа; тек Streamlit элементтері
мен .streamlit/config.toml тақырып баптауларын қолдан.

2. Requests арқылы FastAPI /assessment-tools және /reference-data
маршруттарына GET жібер. Жауапты st.dataframe ішінде кесте түрінде көрсет.
Қосылым және HTTP қателерін пайдаланушыға түсінікті хабарламамен өңде.

3. Іздеу өрісі форма сыртында болсын. st.text_input(live=True) мәнін
requests сұранысының params ішіндегі search параметріне бер. Іздеу
батырмасынсыз кесте жаңарсын. Пән, автор, құрал түрі және балл сүзгілерін қос.

4. st.form ішінде жаңа бағалау құралын қосу формасын жаса. Атауы, пәні,
авторы, түрі, мазмұны және критерийлері болсын. Батырма басылғанда JSON
арқылы POST жібер. Жауап 201 болса st.success көрсетіп, жаңа жазбасы бар
кестеге бірден орал. Валидация қатесінде енгізілген мәндер сақталсын.

5. Жою алдында нақты құралды көрсетіп, растау белгісін сұра.
Бекіткеннен кейін DELETE жібер. Жоюдан кейін деректерді қайта жүкте.

6. Түсіндір: браузердегі форма → Streamlit Python → requests HTTP сұранысы
→ FastAPI валидациясы → SQLModel Session → SQLite → HTTP жауап → жаңарған кесте.
