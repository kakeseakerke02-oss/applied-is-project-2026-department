Мен Python тілінде «Кафедраның бағалау құралдары қоры» ақпараттық жүйесін жасаймын.
FastAPI қолданбасының бастапқы құрылымын дайында. Деректер базасының модельдері
үшін app/database, API маршруттары үшін app/routers, Streamlit интерфейсі үшін
app/frontend папкаларын бөл. fastapi, uvicorn, sqlmodel, streamlit кітапханалары
бар requirements.txt жаса. Нысандар: кафедра, оқытушы, пән, бағалау құралы,
бағалау критерийі. ORM мен база екінші зертханалық жұмыста қосылады.
