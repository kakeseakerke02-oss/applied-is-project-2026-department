1. FastAPI main.py ішінде lifespan арқылы init_db шақыр, GET / күй маршрутын
сақта және assessment_tools роутерін қос.

2. app/database/db.py ішіндегі get_session әр сұранысқа Session ашып,
yield-тен кейін жабатынын тексер. Оны Annotated[Session, Depends(get_session)]
арқылы API маршруттарына енгіз.

3. GET /assessment-tools және GET /assessment-tools/{tool_id} жаса.
Жоқ ID үшін 404 қайтар. Тізімде критерийлерді алдын ала жүкте.

4. POST /assessment-tools жаса. Кіріс пен жауап схемаларын ORM кестелерінен
бөлек ұста. Атау мен мазмұн бос болмасын, критерийдің максималды балы нөлден
үлкен болсын, кемінде бір критерий болсын. ID мен жасалу уақытын клиент
бере алмасын. Құрал мен критерийлер бір транзакцияда сақталсын.
Сәтті жауап 201, валидация қатесі 422, жоқ пән/автор 404, қайталанған құрал
409 болсын. Қате транзакцияда rollback орында, SQL мәліметтерін жариялама.

5. Swagger арқылы GET тізімін, ID іздеуін, POST дұрыс және қате деректерін
сына. Бөлек уақытша базада HTTP тесттерін орында, оқу базасын өзгертпе.
