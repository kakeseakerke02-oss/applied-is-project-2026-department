# ЛР №7: код шолуы

## Тексерілген шешімдер

- SQLModel select/where және параметрленген өрнектер қолданылады. Іздеу contains(autoescape=True) арқылы беріледі; инъекция тәрізді мәтін тестпен тексеріледі.
- Create/Update схемалары id мен created_at қабылдамайды, артық өрістерге тыйым салынған. Бос атау, теріс балл және explicit null 422 қайтарады.
- POST және PATCH критерийлермен бірге бір транзакцияда сақталады; IntegrityError кезінде rollback және 409 бар. Бірегейлік БД деңгейінде бекітілген.
- get_session сессияны with арқылы жабады. Шетелдік кілттер SQLite PRAGMA арқылы қосылған.
- DELETE алдында объект тексеріледі; критерийлер ORM cascade арқылы жойылады.
- Тест сессиясын ауыстыру және lifespan оқшаулауы негізгі базаға кездейсоқ жазудан қорғайды.

## Шектеулер

Бұл — жергілікті оқу жобасы. Авторизация және пайдаланушы рөлдері іске асырылмаған;
API-ға қолжетімді кез келген клиент өзгеріс енгізе алады. Автор ID-ін таңдау тұлғаны растау емес.
Көп пайдаланушыға жариялау алдында аутентификация, рөлдер және TLS қажет.
Бір жазбаны екі клиент қатар өзгертсе, соңғы өзгеріс сақталады; optimistic locking жоқ.
GET тізімі шектелмеген: үлкен қор үшін пагинация қажет. SQLite бір жазушыға бейімделген.

Шолуда дәлелденген жаңа backend ақауы табылмады; бизнес-логика себепсіз өзгертілген жоқ.
Автотесттер барлық ықтимал қауіптің жоқтығын дәлелдемейді.

## Құжаттама түзетулері

README ескірген бастапқы құрылымның орнына толық CRUD, алты кесте және Docker іске қосуын сипаттайды.
Compose version өрісі жаңа Compose нұсқасында ескіргендіктен алынып тасталды.

## Тексеру нәтижесі (2026-11-05)

Python 3.12.14, pytest 9.2.0: `16 passed, 13 subtests passed` (28.54 с).
`pip check`: қате тәуелділік жоқ. `docker compose config --quiet`: сәтті.
Starlette TestClient HTTPX туралы бір deprecation ескертуін береді; тесттерді тоқтатпайды.
Әдістемеде сұралған HTTPX сақталды; келесі кітапхана жаңартуында клиент үйлесімділігін қайта тексеру керек.

контейнерлерді down/up арқылы қайта іске қосу және браузердегі қорғау көрсетілімі пайдаланушы терминалында тексеріледі.
