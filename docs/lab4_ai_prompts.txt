1. AssessmentToolUpdate Pydantic схемасын жаса: өзгертуге болатын барлық
өріс Optional, әдепкі мәні None болсын. Жіберілмеген өрісті өзгертпе.
Міндетті SQL бағанына анық null жіберілсе, 422 қайтар. Бос атау мен теріс
критерий баллын қабылдама. id және created_at өзгертілмесін.

2. PATCH /assessment-tools/{tool_id} жаса. Session-ды Depends арқылы ал.
Жоқ ID үшін 404 қайтар. model_dump(exclude_unset=True) және sqlmodel_update
қолдан. Критерийлер жіберілсе, толық тізім ретінде атомарлы ауыстыр; жіберілмесе
өзгертпе. Қате болса rollback жаса, бірегейлік қақтығысына 409 қайтар.

3. DELETE /assessment-tools/{tool_id} жаса. Бар-жоғын тексер. Құралды және
оған тиесілі критерийлерді session.delete арқылы жой, 204 және бос жауап қайтар.
Бір ID-ға қайталанған DELETE немесе PATCH үшін 404 болсын.

4. GET /assessment-tools ішіне search, discipline_id, author_id, tool_type,
min_score, max_score сүзгілерін енгіз. min_score/max_score критерийлердің
жалпы максималды балын SQL SUM арқылы сүзсін. Қазақша регистрсіз іздеу болсын.
SQL-ге жолдарды тікелей қоспа, параметрленген select/where қолдан.
min_score > max_score болса 422 қайтар. % және _ іздеуде жай таңба болсын.

5. Бөлек уақытша базада толық CRUD тексер: бір өрісті жаңартқанда басқа
өрістер өзгермесін; қате PATCH деректерді өзгертпесін; критерийлерді ауыстыру
атомарлы болсын; DELETE жазбаны және критерийлерді физикалық жойсын;
кейін PATCH/GET 404 қайтарсын; қазақша іздеу мен балл шектері дұрыс болсын.
